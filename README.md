# Entrika

A Muhteşem Yüzyıl social-deduction card game for friends, played in the browser on phones, at the same table or remotely. (Formerly *Sarayda Hain Var!*.)

- `manual.html` is the living rules manual. It is also published as a private artifact: https://claude.ai/artifact/5gQkB81wmjSUCno7w26Eau. Names and flavor text are edited in its Lexicon, which lives in the artifact's database rather than in this file.
- `docs/` has the design sources: the v0.1 rulebook, the original ChatGPT conversation, and the script behind the v0.2 card text.
- `docs/direction.md` is the standing brief for the game: what we're building, the data-driven philosophy, and how we work.
- `plan.md` lists the next steps.

Status: rules at v0.7. The game itself is not started yet.
